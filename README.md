# Harshit Rastogi — Résumé Website

Static, dependency-free personal résumé site (HTML/CSS/JS) with light/dark theme.

## Publish on GitHub Pages
1. Create a repo named `Harsh1t-coder.github.io` (or any name) and push these files.
2. Repo **Settings → Pages → Deploy from branch → `main` / root**.
3. Live at `https://Harsh1t-coder.github.io/`.

## Update
Edit `index.html`; replace `Harshit_Rastogi_Resume.pdf` to update the download.
